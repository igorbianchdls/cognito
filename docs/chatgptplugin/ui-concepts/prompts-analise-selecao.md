# Prévias: análise e seleção

Geradas com a ferramenta integrada de geração de imagens, em 04/10/2026. São conceitos visuais com dados ilustrativos; não representam telas já implementadas.

## Direção do prompt: análise e indicadores

Criar uma interface de alta fidelidade para um card de análise do Cognito dentro de uma conversa do ChatGPT. O usuário pergunta como foram as vendas de julho a setembro. Mostrar apenas as vendas confirmadas de 01/07/2026 a 30/09/2026, sem abas de outros módulos. Interface clara, tipografia legível em português, bordas discretas e destaque teal.

Indicadores ilustrativos: faturamento R$ 292.000,00; 146 vendas confirmadas; ticket médio R$ 2.000,00; setembro 18,8% acima de agosto. Gráfico com exatamente três barras proporcionais: julho R$ 82.000,00, agosto R$ 96.000,00, setembro R$ 114.000,00. Destacar que setembro teve o maior faturamento. Incluir a identificação de dados ilustrativos e o campo de conversa abaixo do card.

## Direção do prompt: seleção

Criar uma interface de alta fidelidade para um card de seleção do Cognito dentro de uma conversa do ChatGPT. O usuário pede uma venda para Atlas e são encontrados três clientes fictícios. Solicitar uma escolha antes de preparar a venda. Interface clara, tipografia legível em português, bordas discretas e destaque teal. Sem abas de outros módulos, indicadores financeiros ou campos de venda.

Mostrar busca por Atlas e três opções inicialmente sem seleção: Atlas Tecnologia, Fortaleza/CE, tecnologia@example.invalid; Atlas Comércio, Campinas/SP, comercio@example.invalid; Atlas Serviços, São Paulo/SP, servicos@example.invalid. Botões Cancelar e Continuar, com Continuar desabilitado até a seleção. Incluir identificação de dados ilustrativos e o campo de conversa abaixo do card. Nenhuma venda é criada nesta etapa.
